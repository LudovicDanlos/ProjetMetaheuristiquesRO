# ProjetMetaheuristiquesRO
Projet de M2 TNSID dans le cadre du cours de Recherche Opérationnelle. L'objectif est de trouver une solution optimale ou approchée pour le problème ALP à l'aide de différentes heuristiques.

| Fichier | Rôle |
|---|---|
| `main.py` | Script simplifier ouvrant une instance et cherchant une solution |
| `instance.py` | Ouvre un fichier `.dat` et l'utilise comme situation de départ |
| `evaluation.py` | Evalue une solution |
| `feasibility.py` | Vérifie que la solution proposé est faisable |
| `constructive.py` | Algo glouton |
