# ProjetMetaheuristiquesRO
Projet de M2 TNSID dans le cadre du cours de Recherche Opérationnelle. L'objectif est de trouver une solution optimale ou approchée pour le problème ALP à l'aide de différentes heuristiques.

| Fichier | Rôle |
|---|---|
| `main.py` | Script simplifier ouvrant une instance et cherchant une solution |
| `instance.py` | Ouvre un fichier `.dat` et l'utilise comme situation de départ |
| `evaluation.py` | Evalue une solution, renvoie score du probleme |
| `feasibility.py` | Vérifie que la solution proposé est faisable, verification des contraintes |
| `constructive.py` | Algo glouton uniquement |

## Progression

| État | Étape |
|---|---|
| ✅ | 1. Formuler le problème (reprendre toute ou partie de la formulation de l’année dernière) |
| ✅ | 2. Concevoir et implémenter la lecture et la représentation des données (classes, méthodes, attributs; etc) |
| ✅ | 3. Implémenter une procédure (ou une classe) qui permet de vérifier si une solution est réalisable ou non |
| ✅ | 4. Implémenter une procédure/algo qui permet de construire une solution initiale (algo glouton) |
| ⏳ | 5. Implémenter une procédure/algo de Recherche Locale + récupérer résultats d’expérience |
| ❌ | 6. Implémenter la procédure/algo VNS + récupérer résultats d’expérience |
| ❌ | 7. Implémenter la procédure/algo TS + récupérer résultats d’expérience |
| ❌ | 8. Faire le ptn de rapport (Description de l’implémentation des données et des algos, résultats de tests, analyses, conclusion etc) |
| ❌ | 9. Festoyer |
